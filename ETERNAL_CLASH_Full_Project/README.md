# ETERNAL CLASH — Unity Project

Original Unity Android MOBA prototype project.

## Open
1. Extract this ZIP.
2. In Unity Hub select **Add > Add project from disk** and choose this folder.
3. Use Unity 2022.3 LTS or newer.
4. Open the project and let Unity import assets.
5. In the top menu click **Eternal Clash > 1. Create Main Scene**, then press Play to test.
6. Click **Eternal Clash > 2. Build APK** (or **3. Build AAB** for Google Play). The file appears in the `Builds` folder.

## Included systems
- Procedural three-lane arena, river, jungle decoration, bases and towers
- 5v5 hero units (one player hero plus allied/enemy AI)
- Minion waves, lane movement and combat
- Basic hero movement, attacks, health, respawn and core victory condition
- Mobile joystick and skill-button HUD
- Original objective monster spawn points and basic shop panel scaffolding

## Scope
This is a playable greybox prototype, not a finished photorealistic game or an APK.
The scene uses procedural placeholder geometry and materials. Production-quality
photorealistic hero models, rigs, animations, detailed environment assets, effects,
sound, complete item/skill balancing, online multiplayer servers, matchmaking,
ranked services and store-ready QA are not included. All game assets and names are
original; no MLBB proprietary assets are included.
